# 프로젝트 실행 방법

## 1. Strapi 서버 실행

1. 터미널을 열고 `server` 디렉토리로 이동합니다.
   ```bash
   cd server
   ```
2. 의존성을 설치합니다.
   ```bash
   npm install
   ```
3. Strapi 개발 서버를 실행합니다.
   ```bash
   npm run develop
   ```
4. 서버가 실행되면 아래 주소에서 접속할 수 있습니다.
   - API: [http://localhost:1337](http://localhost:1337)
   - **Strapi CMS 관리자**: [http://localhost:1337/admin](http://localhost:1337/admin)

### 어드민 사이드바(콘텐츠 타입) 순서와 그룹

Strapi 기본 관리자는 **콘텐츠 타입을 폴더로 묶는 UI를 제공하지 않습니다.**  
그래서 아래처럼 **표시 이름(displayName) 앞에 접두어**를 붙여, 정렬 순서를 맞추고 한눈에 묶여 보이게 했습니다.

- **매뉴얼 그룹**: `[매뉴얼 · 01] …` ~ `[매뉴얼 · 04] …` (문서 → 대·중·소 카테고리 순)
- **그 외 사이트 콘텐츠**: `[사이트 · 01] …` 부터 번호 순

**사용자(User)** 항목은 `Users & Permissions` 플러그인 영역에 있어, 위 **콘텐츠 매니저의 컬렉션 타입 목록과는 메뉴 위치가 분리**되어 있습니다. (플러그인 메뉴 구조는 Strapi가 관리하므로, 공지·FAQ와 같은 줄에 끼워 넣는 방식은 기본 설정만으로는 어렵습니다. 폴더형으로 완전히 통합하려면 어드민 커스텀 개발이 필요합니다.)

### 매뉴얼(CMS) 사용 방법

매뉴얼은 **카테고리(대·중·소)** 를 먼저 만들고, **문서(본문)** 에서 그 카테고리를 선택하는 방식입니다.  
같은 대분류 이름을 매번 손으로 입력하면 오타로 메뉴가 갈라질 수 있어서, 카테고리는 **별도 타입으로 등록**하고 **관계 필드로만 선택**합니다.

#### 1) 카테고리 만들기(순서 권장)

1. **매뉴얼 대분류 카테고리**  
   - `code`: `1`, `2`, `3` … (한 단계 번호)  
   - `title`: 화면에 보일 이름 (예: `현장 운영`)  
   - 저장 후 **발행(Publish)**  
2. **매뉴얼 중분류 카테고리**  
   - `code`: `2-1`, `2-2` … (대분류 번호-순번)  
   - `large`: 위에서 만든 **대분류** 선택  
   - 발행  
3. **매뉴얼 소분류 카테고리**  
   - `code`: `2-1-1`, `2-1-2` … (중분류 번호-순번)  
   - `medium`: 위에서 만든 **중분류** 선택  
   - 발행  

#### 2) “새로 만들기(Create)” 팝업이 헷갈릴 때

**[매뉴얼 · 01] 문서(본문)** 편집 화면에서 관계 필드 옆의 **Create / 새 항목** 을 누르면, **그 관계가 가리키는 카테고리 타입** 전용 작성 창이 열립니다.

- 대분류 필드에서 Create → 제목이 **「[매뉴얼 · 02] 대분류 카테고리」** 인 창 = **대분류 전용**  
- 중분류 필드에서 Create → **「[매뉴얼 · 03] 중분류 카테고리」** = **중분류 전용**  
- 소분류 필드에서 Create → **「[매뉴얼 · 04] 소분류 카테고리」** = **소분류 전용**  

각 콘텐츠 타입의 **설명(description)** 에도 동일한 안내를 넣어 두었습니다. (어드민에서 타입을 열면 상단 설명으로 확인 가능)

#### 3) [매뉴얼 · 01] 문서(본문) 작성

**[매뉴얼 · 01] 문서(본문)** 에서:

- `title`: 문서 제목  
- `largeCategory`, `mediumCategory`, `smallCategory`: 위에서 만든 카테고리 **선택**  
- `subCategory`: 더 잘게 나눌 때만 입력 (없으면 비워도 됨)  
- `sortOrder`: 같은 소분류 안에서 정렬할 때 사용 (숫자가 작을수록 위)  
- `content`: 본문(블록 에디터)  
- 저장 후 **발행**해야 프론트에서 보입니다.

#### 4) 테스트 데이터 주입(선택)

`server` 디렉토리에서 아래 명령을 실행하면 예시 카테고리·문서가 한 번에 들어갑니다.

```bash
npm run seed:manual
```

이미 **매뉴얼 문서**가 1개 이상 있으면 중복 방지를 위해 건너뜁니다.

#### 5) 프론트에서 보기

프론트에서 **매뉴얼** 메뉴 → `/manual` 로 이동하면, 좌측 사이드바에 **대분류 → 중분류 → 소분류** 트리가 보이고, 말단에서 문서를 누르면 상세로 이동합니다.

## 2. 프론트엔드 개발 서버 실행

1. 의존성을 설치합니다.
   ```bash
   npm install
   ```
2. 프론트엔드 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```
3. 서버가 실행되면 아래 주소에서 접속할 수 있습니다.
   - [http://localhost:5173](http://localhost:5173)

---

각 서버는 별도의 터미널에서 각각 실행해야 합니다.
